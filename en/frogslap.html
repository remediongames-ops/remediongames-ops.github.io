The game

Easy to learn.
Hard to put down.

FrogSlap is a fast-paced mobile arcade game. Every run asks you to decide which frog goes first, which power can save you, and how long you can keep up with the chaos.

01

Slap & React

Different enemies demand different reactions. Slapping blindly can hurt.

02

Build Your Run

Choose powers, combine runes, and refine your playstyle between runs.

03

Defeat Bosses

Each world raises the difficulty, with its own boss and special rewards at the end.

04

Embrace Chaos

Finish the standard run to unlock Chaos Mode. It lives up to its name.

Progression

Ten worlds.
Each with a bang.

Start in the forest and cross increasingly dangerous areas on your way to the lab. New enemies, power-ups, runes, maps, and relics keep each run different.

Google services

Only data required for these features is requested. This may include a Play Games profile, player ID, achievements, and leaderboard data. It is not used for unrelated purposes.
